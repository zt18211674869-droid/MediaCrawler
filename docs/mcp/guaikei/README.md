# GUAIKEI 社媒 MCP 说明

GUAIKEI 社媒 MCP 可以让 AI 获取小红书、抖音、快手和 TikTok 的社媒内容与互动数据。各平台支持的获取方式如下。

## 能取什么数据？

| 平台 | 可以获取什么 |
| --- | --- |
| 小红书 | 关键词搜笔记、笔记详情、评论、博主笔记；标题、正文、作者、发布时间及点赞、收藏等互动数据。 |
| 抖音 | 关键词搜作品、作品详情、评论、博主作品与主页数据；文案、作者、链接及点赞、评论等互动数据。 |
| 快手 | 关键词搜视频、视频评论、博主作品与主页互动数据。 |
| TikTok | 关键词搜视频、视频评论、博主已发布作品。 |

## 怎么用？

完成 MCP 连接后，直接告诉 AI：**用 GUAIKEI + 平台 + 关键词或链接 + 数量 + 想要的结果。**

例如，搜索笔记：

> 请使用 GUAIKEI MCP，搜索小红书上“AI办公”相关的 5 条笔记，用表格列出标题、作者、发布时间、点赞数和笔记链接。请使用实际返回的来源链接。

或者获取评论：

> 请使用 GUAIKEI MCP，获取这篇小红书笔记的 20 条评论，总结 3 个主要观点，并附评论原文和来源链接。笔记链接：[粘贴完整链接，保留 xsec_token]

可用工具、返回字段与可获取数量，以当前服务及账号权限为准。

## 安装与配置

[打开客户端安装与配置指南（在线阅读）](https://zt18211674869-droid.github.io/MediaCrawler/mcp/guaikei/)

安装指南包含不同客户端的配置方式、连接测试和快速试用示例，可以直接在线阅读。也可以下载 [HTML 文件](index.html) 后用浏览器打开；文中的图片已内嵌。

使用前需要准备支持相应连接方式的客户端，以及有效的服务 TOKEN。配置中的 `fake_token` 是占位符，需按指南替换为自己的凭据。

当前 HTML 来源于 `小红书等社媒MCP安装说明1106.html`，以 `index.html` 作为后续维护的稳定文件名。具体客户端配置与可用工具以实际版本及账号权限为准。
