CLIENT 02 / 10配置文件 / 命令行

Codex

先联系相关负责人获取 TOKEN，再按你的操作系统选择下方步骤。Codex 通过环境变量 GUAIKEI_API_TOKEN 读取 TOKEN。

macOS：发指令给 Codex ↓Windows：手动配置 ↓
MAC

macOS · 让 Codex 帮你配置

复制下面整段指令，直接发给 Mac 上的 Codex，让它执行配置。

发给 Codex 的配置指令 TEXT
请帮我配置 Codex 的 GUAIKEI MCP（Streamable HTTP）。

要求：
1. 优先用 CLI（若本机有 codex 命令）：
   codex mcp add GUAIKEI --url https://www.guaikei.com/mcp --bearer-token-env-var GUAIKEI_API_TOKEN
2. 或编辑配置文件：
   - macOS/Linux: ~/.codex/config.toml
   - Windows: %USERPROFILE%\.codex\config.toml
   写入（若已有 [mcp_servers.GUAIKEI] 则合并更新，不要删掉其它 mcp_servers）：
   [mcp_servers.GUAIKEI]
   url = "https://www.guaikei.com/mcp"
   bearer_token_env_var = "GUAIKEI_API_TOKEN"
   tool_timeout_sec = 120
3. 确认当前用户/会话环境变量 GUAIKEI_API_TOKEN 已设置为我的私有 TOKEN（不要把 TOKEN 明文写进 config.toml，也不要回显完整 TOKEN）。
4. 配置完成后告诉我：改了哪个文件或执行了哪条命令；如何验证（例如重启 Codex / 列出 MCP 工具）。

注意：这是远程 HTTP MCP，不要配成 stdio/command；鉴权只用 Bearer，经 bearer_token_env_var 读取环境变量。

完成后，按 Codex 给出的方式重启并验证；确认启动 Codex 的环境能读取 GUAIKEI_API_TOKEN。

WIN

Windows · 先设置环境变量，再添加配置

1. 设置环境变量（必须完成）

开始 → 搜索“系统环境变量” → 打开 → 高级 → 环境变量 → 新建
  1. 点击电脑任务栏的开始菜单（Windows 窗口图标）。
  2. 搜索“系统环境变量”，打开“编辑系统环境变量”。
  3. 在“系统属性”窗口的“高级”选项卡下，点击“环境变量”。
  4. 在上方“用户变量”区域点击“新建”；若已有 GUAIKEI_API_TOKEN，选中后点击“编辑”。
  5. 填写变量名 GUAIKEI_API_TOKEN；变量值填写 TOKEN（请填写联系相关负责人获取的真实 TOKEN）。不要填写 fake_token，也不要加 Bearer 前缀或引号。
  6. 依次点击“确定”，保存并关闭各个窗口。
变量名
GUAIKEI_API_TOKEN
变量值
TOKEN（请填写真实 TOKEN）
查看“高级 → 环境变量”入口截图

2. 添加 GUAIKEI MCP（以下两种方式任选一种）

方式 A · 编辑 TOML 配置

打开 %USERPROFILE%\.codex\config.toml，写入以下内容。若已有 [mcp_servers.GUAIKEI]，合并更新该段，保留其他 mcp_servers 配置。

TOML 配置 TOML
[mcp_servers.GUAIKEI]
url = "https://www.guaikei.com/mcp"
bearer_token_env_var = "GUAIKEI_API_TOKEN"
tool_timeout_sec = 120

方式 B · 在终端执行命令

本机有 codex 命令时，可以打开一个新的 PowerShell 或终端窗口，执行：

也可执行 SHELL
codex mcp add GUAIKEI --url https://www.guaikei.com/mcp --bearer-token-env-var GUAIKEI_API_TOKEN

两种方式都需要第 1 步的环境变量。TOKEN 仅放在环境变量中，config.toml 中保留变量名 GUAIKEI_API_TOKEN。

3. 从系统托盘退出 Codex，再重新打开

  1. 在 Windows 任务栏右下角的系统托盘（通知区域），点击箭头展开隐藏图标。
  2. 找到 Codex 图标，右键 → 退出。
  3. 退出后，从开始菜单或桌面快捷方式重新打开 Codex，使环境变量生效。

注意：只点击窗口右上角的 × 关闭窗口，Codex 可能仍在后台运行，无法重新加载环境变量。请务必从系统托盘选择“退出”后再打开。使用 CLI 时，也要关闭旧终端并重新打开。

在终端执行 codex mcp list 可确认 GUAIKEI 已列入配置；在 Codex CLI 对话中使用 /mcp 查看活动服务器，再查看或列出 GUAIKEI MCP 工具确认连接。

Codex 配置字段与 CLI 验证方式参考 OpenAI 官方 MCP 文档；GUAIKEI 服务参数由提供的材料确定。

  1. 在左侧点击 专家·技能·连接器。

查看连接器入口截图
02

填写配置，保存并返回列表

复制下面的完整 JSON，将 fake_token 替换为从相关负责人处获取的 TOKEN。保留 Bearer 后面的空格。

已有其他 MCP 配置时，把 GUAIKEI 条目合并到原来的 mcpServers 对象中，保留其他服务。

JSON 配置 JSON
{
  "mcpServers": {
    "GUAIKEI": {
      "type": "streamableHttp",
      "url": "https://www.guaikei.com/mcp",
      "headers": {
        "Authorization": "Bearer fake_token"
      },
      "timeout": 120000
    }
  }
}

Windows 用户级路径示例为 %USERPROFILE%\.workbuddy\mcp.json；编辑页上方会显示实际路径。示例中的 type 为 streamableHttp，timeout 保留 120000。

03

完成首次信任，确认启用

  1. 首次连接出现“首次连接此 MCP 服务需要您的信任确认”时，点击 信任。

  3. 回到 WorkBuddy 任务中，按下方 连接测试 检查 GUAIKEI 工具，并用 快速试用 的小任务确认能实际取得数据。

CLIENT 10 / 10接入速查

其他客户端

通用要求：传输选 Streamable HTTP（或 HTTP），URL 为 https://www.guaikei.com/mcp，请求头 Authorization: Bearer 您的TOKEN。

01

Claude Desktop

配置文件仅支持本地 stdio；远程请用 npx mcp-remote。Connectors 若要求 OAuth，本服务不适用。

02

OpenCode

opencode.json 中 type: remote，并设 oauth: false。

03

Copilot CLI

~/.copilot/mcp-config.json，type: http。也可 copilot mcp add --transport http。

04

Cline

须 type: streamableHttp，省略可能按 SSE 连接失败。

05

Devin Desktop（原 Windsurf）

~/.config/devin/mcp_config.json；Windows 为 %APPDATA%\devin\mcp_config.json。

06

Roo Code

.roo/mcp.json，type 必须为 streamable-http（带连字符）。

07

Continue

写入 config.yaml，type: streamable-http，apiKey 即 Bearer TOKEN。

08

Cherry Studio

设置 → MCP → 添加；type: streamableHttp。添加后需绑定到 Agent。

09

扣子

扩展 → MCP → 添加自定义 MCP，粘贴含 url 与 headers 的 JSON。保存到「我的 MCP」后，绑定到具体 Agent。

10

Zed / Goose

Zed 使用 context_servers；Goose 使用 type: streamable_http 与 uri。

11

网页端与其他入口

ChatGPT、Claude.ai、Gemini 网页版自定义连接器通常走 OAuth，本服务不适用。通义灵码 IDE / Qoder CN 目前以 stdio、SSE 为主；豆包网页端以产品当前版本为准。不支持填写 URL 与请求头时，请改用 FAQ 中的 SKILL。
