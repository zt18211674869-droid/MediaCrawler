# 使用案例

这里分享实际使用过程和结果，供读者借鉴与复现，

每个案例使用独立目录，以 `README.md` 说明以下内容。

1. 背景与目标，说明要解决的问题和适用场景。
2. 使用工具，链接到对应的 MCP 文档、技能包或脚本。
3. 操作过程，提供实际提示词、步骤或命令。
4. 结果与产出，按需附报告、截图或结果示例。
5. 经验与局限，说明适用条件和复现时需要调整的地方。

按实际需要加入 `sample-data/`、`assets/` 或报告文件。示例数据使用可公开、脱敏的小样本，通用技能和脚本通过链接引用，避免重复维护。
