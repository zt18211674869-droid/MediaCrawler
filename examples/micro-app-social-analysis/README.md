# 微应用生成工具的社媒用户体验分析

## 背景

在微应用生成产品的竞品研究中，通过社交媒体原帖了解用户的实际使用场景、认可点和使用障碍，为产品分析提供参考。研究涉及灵光、秒哒、Today、Muse 和 WorkBuddy，重点关注应用生成及后续修改、运行与使用体验。

## 使用工具

使用 [GUAIKEI MCP](../../docs/mcp/guaikei/README.md) 获取小红书、抖音的搜索结果与原帖内容，通过 AI 助手辅助筛选、整理和分析，并由研究者校准范围与判断标准。
