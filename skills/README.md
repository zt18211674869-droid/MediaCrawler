# 技能包

这里收录可以复制、安装和使用的完整技能包，目前尚未加入具体技能。

每个技能使用独立目录，入口文件命名为 `SKILL.md`。

```text
skills/
└── <skill-name>/
    ├── SKILL.md
    ├── references/  # 参考材料，按需添加
    ├── scripts/     # 随技能使用的脚本，按需添加
    └── assets/      # 模板等资源，按需添加
```

安装时保留整个技能目录，具体安装位置和依赖由各技能说明。独立执行的通用分析脚本放在 [scripts/](../scripts/README.md)，案例通过链接引用技能。
