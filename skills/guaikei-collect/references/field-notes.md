# 怪 K 采集实战记录

## 决定搜什么、搜多少

| 遇到的情况 | 执行办法 |
|---|---|
| 一串关键词里有产品名、型号和带空格的短语 | 每次搜索只传一个词。保留短语内的空格和每条作品命中的全部词。多个词、排序或平台可产生多项请求，先给用户看请求数。 |
| 同一个时间选项在两平台含义不同 | 抖音 MCP 的一天、一周、半年依次传 `time=1/7/180`，小红书传 `1/2/3`。半个月用两端的半年档覆盖，再按原帖发布时间回筛 15 天。抖音 MCP 用 `time/sort`，直接照抄项目 HTTP 的 `publish_time/sort_type` 会传错字段。 |
| 精确日期或跨午夜续跑 | 弹窗的最近 N 天按启动时刻回推，续跑复用同一北京时间窗口。项目历史的「昨日对账」按自然日取昨天零点至今天零点，两种窗口的首尾不同。先筛原帖，再安排补采。日期文字和时间戳跨越入选边界时，保留两项证据，单列待核。 |
| 结果很少，或想提高召回 | 高覆盖任务可在同一时间档组合最新与综合，两平台的最新排序分别是抖音 `2`、小红书 `1`，综合均为 `0`。小红书一次七词回放中，最新每词只返回 16–19 条，补综合仍多找到 443 篇。按通道记录原始数、窗口内数、独有新增数和触顶情况。有额外请求时仍受本轮已选范围和预算约束。 |
| 如何分配请求数量 | 网页新建实时采集对每个平台、关键词分别用最新和综合搜索，每组上限 1,000 篇，后端采集队列默认共享 20 个名额。Skill 默认只搜最新，每组同样取至多 1,000 篇，每轮并发可设为 1–10，默认 10。两边单帖评论和回复合计上限均为 5,000。勾选评论时，Skill 对已知评论数较少的帖子按需缩小请求量。 |

## 决定哪些数据值得补取

- **先去重，再补采。** 作品按「平台＋作品 ID」，评论按「平台＋作品 ID＋评论 ID」，作者按「平台＋账号 ID」。保留父评论 ID 和原始来源，ID 全程用字符串，包括导出到 Excel。相同昵称不足以合并账号。已有完整且与作品 ID 匹配的详情可复用。
- **增量更新。** 旧帖保留首次发现、原始发布时间和历次命中词。搜索漏回的历史帖保留在库。正文变化留版本，互动指标变化留快照。已勾选评论时，平台计数为零可跳过。计数变动或此前未成功采过再补。缺计数记为待核。计数持平只说明本轮可按策略跳过。同一任务 ID 和相同回包指纹代表缓存复用，保留上一次确认的新鲜度。
- **选作者时只查原帖作者。** 用抖音 `sec_uid` 或小红书 `user_id`/主页链接查主页，`limit=0` 只取账号资料。同一作者多帖命中只查一次。评论开关只取原文与随附字段。评论者主页将额外产生逐人请求。
- **评论覆盖单独核算。** 小红书 `expired_at` 只约束评论时间，单选原帖日期时无需照搬。分别统计一级评论、回复、平台声明的回复数、缺失数和触顶。一次抖音回填中有 320 篇取得评论，仍有至少 22,027 条楼中楼缺口。缺少分页游标或结束信号时，只报告已取得的数据。

## 调用异常时怎么继续

| 状态 | 下一步 |
|---|---|
| 已受理、处理中或 `TIMEOUT` 带 `request.id` | 保存平台、工具、原参和回执。等本次调用返回后用原工具原 ID 续查。慢任务可退出本地工作槽，保留待续查状态。已受理的远端任务仍计入在途预算。 |
| 超时且未取得 ID | 记为「受理待核」，先核对原请求。重复提交可能另外计费。 |
| 429、业务码 17、鉴权失败 | 429 按上游指示退避并降低并发。码 17 提示额度可能不足，暂停受影响的新请求并核对额度。项目里仅 1 条评论的帖子也曾遇到。鉴权失败等凭据修复再继续。 |
| `INVALID_ARGS`、`INVALID_URL` | 记录错误并核对原字段。作品详情和评论用作品链接或 ID，主页用账号链接或账号 ID。业务参数纠正后再提交。禁止改成默认条件重跑。 |

## 控制 token 和下游分析范围

原始回包只归档一次。批次间传文件位置、任务 ID、统计、缺口和少量样本，后续只读所需字段。已知评论数的小帖按需求取量，热门帖限制单帖预算。历史样本中两篇偏题热门帖带回 12,653 条无关评论，值得先抽查宽泛关键词。另一次回放里约 83% 的相关评论来自原帖未命中标签的作品，评论相关性仍需独立判断。这两组数字用于解释取舍，不能换算成本次节省的 token 或费用。

如需后续分析，按评论或回复自己的发布时间归周，时间缺失、超出报告范围或早于所属原帖的记录保留在原档并列出异常。账号粉丝规模、账号身份和单帖营销证据分别记录。缺少认证、简介或商业证据时标为待核。采集完成后，按用户本轮要求决定是否进入打标、聚类、周报或导出。
