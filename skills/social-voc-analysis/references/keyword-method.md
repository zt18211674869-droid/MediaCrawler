# 关键词与正负向词云

词语分析负责找到值得解释的表达，并把读者带回观点与上下文。先定义问题、对象、文本范围与计数单位，再提词；不能先凑满漂亮词云再找含义。

## 提取与归并

1. 保留原文及来源ID，清理重复转载、URL、模板尾注、无分析意义的表情和推广口号。是否移除品牌名、搜索词需按问题决定；不把业务词直接当噪声。
2. 候选可用中文分词/短语抽取，也可逐观点做语义抽取。领域词典保留产品名、任务词和短语边界；停用词与同义词表记录版本。无须为了提词安装新环境。
3. 每条候选保存 `surface`（原文连续片段）、`label`（归并后的表达）、对象/方面、极性、观点与来源ID、归并理由。label可概括，不能冒充逐字原声；需回查所有成员是否表达同一意思。
4. 保留否定、程度、条件与时间。“不方便”“方便”“希望方便”不能合并为正向“方便”；“以前难用、换了以后省事”须分别核对对象；询问、期待、行为不自动等于已发生体验。
5. 复核高覆盖词、歧义词及反例；主题归并与词语归并分别维护。相同词可属于不同主题，不因有某个字就自动打同一标签。

## 计数与极性

- **TF**是词在规定文本中的出现次数，适合看用词强度，容易受长文、重复话术影响。
- **DF**是包含词或归并表达的去重文档/来源数，适合看本样本覆盖。明确“文档”是作品、评论还是来源单元；同源重复提及只计一次。
- **TF-IDF**用于找相对语料的区分性词，须记录实际算法、分词、语料与参数；它不是满意度、重要性或效果评分。未执行就不声称使用。

“独立来源DF”指去重来源单元，不保证作者或事件相互独立；同帖评论、同作者材料仍可能相关。观点数与可辨认账号数另算，不从DF推断人数。

正负云默认纳入符合资格的亲历自述观点，按归并表达的独立来源DF计数，且自述不等于已经核验真实使用。供应方宣传、推荐、期待、咨询与背景材料独立展示或可切换，不能混入“用户好评”。方面级正负向先核对象与上下文；中性、混合不强行二分，词语极性无法确定时保留待核，不擅自修改观点层既有枚举。一源可同时支持不同正负表达，因此双云来源数不必相加为总样本。

如显示覆盖率，分母是当前筛选下符合既定资格的来源集合，并注明是否仅限含正/负评价的来源；不能筛完词再悄悄更换分母。词表需保留DF、来源ID、观点ID和原词，支持复算及逐条回链。

## 展示与诚实说明

正负两面采用相同字号映射及公共取值范围，显式标“正向/负向”，不只依赖红绿。若使用平方根/对数变换，说明变换的是字号还是面积；文字长度不同，不宣称视觉面积严格等于频次。提供排序明细和准确数字，点击词进入成员原声；排不下时缩减显示并保留完整词表，不挤成无法阅读的小字。具体样式见 [report-design.md](report-design.md)。

交付注明实际方法、词典/归并版本、语料资格和日期。例如“逐观点语义提取并归并，按独立来源计算DF”，不能写成“微词云分析”或“TF-IDF提取”，除非确实执行。工具是否使用与方法借鉴分开说明。

## 可执行数据契约

独立文件 `keyword-coding.json` 使用 `meta.schema_version=keyword-coding-v1`。meta记录 `source_opinions/source_opinions_sha256` 与 `source_evidence/source_evidence_sha256`，相对路径位于本轮目录，哈希对应实际源字节。`terms` 保存 `id/label/definition/polarity` 及归并边界；`mentions` 保存 `id/term_id/opinion_id/evidence_id/source_key/product/evidence_role/polarity/surface/reason`。ID桥接到冻结观点和来源，产品与用途一致；同一观点/词项组合不重复。每个观点有一条 `opinion_reviews`，含 `opinion_id/term_ids/reason`；不提词时数组为空并说明原因。

短语方向与原观点不同（例如保守降为中性）时，逐条记录 `source_polarity`、`polarity_basis=explicit_phrase_subset`、`polarity_reason`，保留原编码，不借此任意翻转评价。surface及可选quote须为连续原文；source_key沿用来源display_key，无此字段则用evidence.id。方向差异记录仅便于审计，仍需语义复核。校验入口见 [SKILL.md](../SKILL.md#校验与运行环境)。

## 借鉴来源与边界

参考微词云的[正负面词云教程](https://www.weiciyun.com/blog/sentiment_02/index.html)，采用正负词表分开、保留统计明细的思路；参考[关键词定位上下文教程](https://weiciyun.com/blog/wenbenfenxi-01/)，采用词语到原文的追溯及领域词典。其中在线分词产品仅为历史方法出处；本 Skill 不调用在线分词、不上传材料，词语处理在本地完成。官方教程说明的是产品做法，不能据此认定分类质量；不采纳“高分证明分类好”或“分布异常就说明注水”等未经验证的判断。
