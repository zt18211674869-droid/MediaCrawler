# 按问题选择分析模块

先把用户目的写成可回答的问题，再选证据、方法和视图。下表是能力框架，不是固定目录。核心模块每轮都要落实，但可合并呈现；选配模块须解释它怎样帮助回答主问题。用户点名的模块应回应，缺证据时说明能回答到哪里，不补造内容。

## 模块与证据门槛

| 模块 | 要回答什么 | 最小证据与可计算指标 | 不能推断什么 |
|---|---|---|---|
| 核心：问题与范围 | 为谁解决什么理解或决策问题 | 意图依据、对象身份、平台/窗口、问题—方法对应；子问题已回答/部分回答/未知 | 条数达到目标不等于问题解决 |
| 核心：样本资格 | 材料能支持哪类判断 | 来源、去重键、采集与发布时点、纳入理由、性质；召回/取得/纳入来源数、各性质覆盖、缺失数 | 搜索结果不是总体抽样；账号数不等于用户数 |
| 核心：观点与聚类 | 用户具体评价什么，分歧来自哪里 | 对象＋方面＋判断＋条件、连续原声、资格；主题独立来源数、观点数、方面极性构成 | 高频不等于重要；多主题比例不可默认相加；极性不是情绪强度 |
| 核心：结论与原声 | 哪些回答成立，边界是什么 | 支持、反例/边界材料、研究者解释与缺口；结论支持来源覆盖、可回链状态 | 不以引用数量证明因果；不能把宣传当满意度 |
| 选配：竞品比较 | 同一任务下定位、优势、不足如何不同 | 身份核验、共同维度、各家证据性质；产品×方面来源覆盖、体验正反例 | 样本声量不是市场份额；未提及不是缺功能；不等量证据不强排总分 |
| 选配：词语与词云 | 哪些评价表达值得深入看 | 原词、归并规则、对象/极性、来源ID；独立来源DF及明确分母的覆盖率 | 不从孤词判情感；词云不能代替主题与机制。见 [keyword-method.md](keyword-method.md) |
| 选配：场景与旅程 | 在什么情境/阶段做什么、关注什么、怎样应对 | 触发、任务、阶段、行为、关注点、原声；阶段来源数、障碍/补救覆盖，情绪证据 | 汇总片段不是同一个人的连续经历；无过程观测不算转化/留存/成功率。见 [journey-method.md](journey-method.md) |
| 选配：心理模型 | 用户如何理解产品、形成预期与取舍 | 明说的预期、实际体验、应对及反例；模型对应来源与适用条件 | 研究者假设不是真实心理诊断；单段材料不定义人群人格 |
| 条件：时间变化 | 同口径观察是否出现变化 | 可比连续窗口、固定检索/渠道与资格、缺采记录；各窗数量、占比与基数 | 搜索排名、补采策略变化不能当市场趋势 |
| 条件：传播与风险 | 信息如何流动，哪些问题值得处理 | 转发/引用关系及时间；投诉对象、后果、时效；节点/链路、独立风险来源覆盖 | 点赞不等于认同人数；无链路不画传播因果；极端单例不代表普遍危机 |
| 条件：行动与验证 | 用户需要行动时，下一步验证什么 | 对应发现、后果、目标、未知与可验证结果；覆盖、阻断程度，已知成本 | 不用虚构权重或未经观测的业务KPI证明收益 |

## 统一指标口径

每个进入报告的指标记录 `name / unit / numerator / denominator / eligibility / window / dedup_key / multi_label / missing_policy`；单纯计数的分母写“不适用”。分母必须包含同资格、同窗口、同对象的可评估材料。缺失与未知单列，不当作零或中性。

本样本声量默认是去重来源单元覆盖，作品正文与评论分别注明；同源拆分不增加来源数，来源去重不保证作者或事件相互独立。有可靠账号键才统计可辨认账号，不能称真实用户数。观点极性统计用观点作单位，情绪另编码有证据的焦虑、安心等状态，不能由正负标签自动生成。

多标签主题覆盖允许重叠，明确“各项不可加总”；互斥主分类才可展示总计为100%的构成。来源、观点、作品、账号指标不可混用。小基数以数量为主，需要分布时显示 `n/N` 及必要比例，不用精细百分比制造确定感。

模块是否采用由问题决定；一旦用户要求频次、占比或主导分布，对应模块的定量产物就进入完成标准。按 [quantitative-analysis.md](quantitative-analysis.md) 明确模式、分类轴与必需统计表，不能因场景旅程是选配就跳过已明确的场景分布需求。

## 收束与验收

在 research-spec 中保存选用模块、对应问题、证据门槛与不采用原因。完成后回查：每模块是否增加了答案，每个主要结论能否到原声，哪些缺口会改变判断。删去只有装饰作用或重复结论的模块；保留影响结论的未知。
