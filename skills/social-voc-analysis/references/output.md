# 把分析组织成可深入阅读的报告

成稿前读取 [report-language.md](report-language.md)。本文件规定信息如何组织；语言规范负责将分析记录写成正式报告，不能把字段完整视为正文合格。

## 总览清楚，主体保留推理

动笔前沿用 research-spec 的读者用途、主问题、方法与完成标准，把必须回答的问题排出主次。先确定主要章节要回答什么、核心意思及支持材料，再选择展示形式；不从固定模板反推内容。概览呈现主答案和关键问题，主体解释差异与成立条件，详细证据和方法支持复查。

总览先给直接回答和关键差异，必要限定融入对应判断；主体展示从观点到场景、解释和结论的推导。整篇不设固定字数；深度由问题、证据和用户要求决定。

“结论”和“总结”通常合并为总览，避免两段重复开场。采集范围简短可见，通用研究限制与方法细节集中到“原声与方法”。删除总览末尾的阅读指引、点击教学和制作过程说明；主题、词云下方不反复讲同一套统计原理。样本多不等于必须写长文，内容少也不能省略支撑重要判断的过程。

## 以发现组织正文，按需要组合证据

先形成回答主问题的发现，再选择表达形式。关键统计说明规模、集中程度、差异或分化；具体场景与原声说明任务条件、使用方式和评价理由；行为路径帮助解释尝试、替代、继续或放弃的过程。设计建议或研究意义跟随有依据的解释，不以频次直接推导因果或优先级。

每项发现保留能改变判断的材料。数字不能自行解释用户动机，多个相似引语也不能代替分布统计；需要两种证据时应在同一判断附近建立关系。缺少规模证据的案例可以解释具体价值，明确其适用范围；没有必要引语的精确比较可以直接用表格。无需每项都凑齐数字、引语、图表和模型，也不固定数量与文字的篇幅比例。

发现节说明有证据的判断，建议节说明拟采取的行动，讨论节保留未决问题，不要求每节都写成结论。复杂内容先给核心意思，再展开支持、解释和意义；一句话能说清时不硬拆分。不将内部关系渲染为固定标签，避免只报数字、重复报数或仅讲故事。

完整分析与读者展示分别安排：

| 交付位置 | 作用与取舍 |
|---|---|
| 主报告 | 回答主问题，呈现核心发现、必要规模依据、可解释场景及意义；同一判断通常选择一种主要表达 |
| 完整统计与证据入口 | 提供所需分布、细分维度、未知项、完整分子/分母及原声浏览，供读者追问和核查 |
| 分析与校验附件 | 保存原始资料、逐条编码、分类规则、复核及复算记录，支持审计与再分析 |

这些是信息层次，可按任务合并为同页或不同文件，不强制增加页面。按 research-spec 记录哪些统计进入正文、哪些在完整统计中提供及选择理由。精简展示不减少用户已要求的采集、处理、编码或统计范围。用户明确需要仪表盘或统计附表时按其用途安排。

使用场景是正文需要保留定量摘要的模块：场景解释旁应有数量或分布，交代 `n/N`、必要比例及未知项，再用代表案例解释选择和行为。完整细表可下沉，但正文不能只留场景名称、价值描述和原声。缺少足够材料时说明已确认条数与统计缺口，不补造比例。

## 根据目的组织视图

根据 [module-framework.md](module-framework.md) 的已选模块组织视图。竞品研究可采用以下视图，按任务调整名称与内容；用户指定的分类、旅程或心理模型应明确回应，资料不足时说明具体缺口。

| 视图 | 独立回答的问题 |
|---|---|
| 总览 | 主要分化与核心结论是什么，哪些尚不能判断 |
| 竞品比较 | 相同任务/维度下，各家定位、优势、不足与适用条件怎样不同 |
| 观点分类 | 哪些具体观点形成主题，正反体验、情境和产品差异是什么 |
| 关键词与词云 | 具体正负评价集中在哪些表达，怎样回到原词与语境 |
| 场景与旅程 | 问题在哪个环节出现，用户如何应对，后续发生什么 |
| 用户心理模型 | 用户怎样理解产品与判断好用，有哪些预期、取舍和反例 |
| 原声与方法 | 从哪里得到证据，原文与上下文是什么，采样和口径有何边界 |

这些是可选视角，数量随问题与证据决定。连续论证适合章节与目录；确有独立浏览任务时可使用 Tab 或独立视图。不固定章节、页签、卡片数量或全文字数；非竞品任务不硬加产品排名，未要求行动建议时不强填设计方案。

## 让展示形式承担阅读任务

| 读者任务 | 组织方式 |
|---|---|
| 快速抓住答案 | 明确结论与关键问题，保留会改变判断的条件 |
| 比较对象或方案 | 同维度对照表；证据可比时再用图表 |
| 理解场景和行为 | 需求与行为矩阵，或标明来源与时间的路径 |
| 决定改进顺序 | 建议、依据、具体措施与验证方式对应，说明排序理由 |
| 核查结论 | 就近证据入口、必要原声及完整方法与数据 |

按内容选择，不要求五类全部出现。每个段落、表格和图表承担明确作用；删除同一观点的反复改写，不把长段落逐格搬入表格。先删冗余、确定主次，再使用折叠或分页；会影响判断的事实、差异和条件保留在对应阅读位置。

## 比较与主题展开

比较对象身份明确，选择理由可说明；用户指定对象均须覆盖。原型、合集、纸本等按性质单列，同名未核不统一排名。各家使用共同维度，未知不能用叉号暗示不支持，材料性质不同不能用分数掩盖。

一个主题先给简明判断、正反差异和代表原声，再提供筛选后的观点列表；场景、行为、详细定义等按需展开。未知与证据性质保留，改变判断的条件就近写清；不将每条台账字段都做成常驻说明。

正文使用具体主题和结论，不以“研究者归纳”“边界与反例”“反向声音”作为通用段落前缀。其他评价未必推翻当前主张；区分实际反证、不同看法与适用条件，再按读者需要呈现。支持来源中的同一原文只展示一次，不把完整引文再复制成所谓观点概括。

同一发现可以出现在总览、比较与旅程中，但各处承担不同作用：摘要概括、比较定位差异、深读补充推理。共用发现与证据ID，不把同一段复制成多套卡片。台账字段完整不等于正文逐字段渲染。

关键词模块可用正负双云呈现评价表达，保留准确排序明细、当前资格和计数单位；供应方用语另列，原词与归并标签可回查。提取流程、算法名称与统计细则放方法页，不占用词云下方的主要阅读区。按 [keyword-method.md](keyword-method.md) 提取，按 [report-design.md](report-design.md) 共享尺度展示，不能用词云替代主题分析。

旅程以汇总矩阵展示阶段、行为、关注点、证据情绪、障碍/补救及度量，见 [journey-method.md](journey-method.md)。已观测的来源覆盖与未来需验证的完成率、留存等分别标识，不把可提出的指标当作已有结果。

## 原声可浏览，完整台账可下载

正文就地呈现最有解释力的连续原声，产品和来源性质可见，时间与完整上下文可查。每条保留一个清楚的来源入口，避免卡片上下重复链接与编号。原声视图可搜索、筛选、定位来源；完整证据另提供CSV/JSON下载，不只留下不可读的数据文件。

完整原文可放独立 evidence.html 或按来源加载的证据视图，不塞进长篇正文后以折叠掩盖冗余。方法、编码和采集日志保留在包内；关键限制始终跟随相关结论。

方法部分按 [coverage.md](coverage.md) 区分取得数量、逐条处理数量、未处理与待核数量，并提供逐条处理结果。正文仅引用代表案例可以成立，但不能以精选例子代替全量分析，也不能把入账覆盖率写成观点完整率。缺少逐条语义复核记录时，说明当前可验证的覆盖层次，不笼统承诺“全部分析完成”。

## 快照与兼容

沿用原 raw、manifest、items 和 analysis 快照。需要重新提取一源多观点时，可按 [opinion-contract.md](opinion-contract.md) 新建 opinions.json，记录来源文件哈希、再分析日期和编码版本，保留旧判定。各视图和导出复用同一冻结观点层与统计口径。

修改以最新有效文件和用户手改为准，尊重局部范围，不擅自恢复已删除内容；收到一处纠正后检查同类问题。新要求仅替代冲突部分，已确认样例用于校准表达，不照搬案例结论。仅换版式不声称重新分析；未重新采集时保留原采集日期，产品事实注明核验时点。文件用日期或版本号区分。

## 交付验收

统一交付入口、问题回答矩阵和 quality-review 记录按 [运行规范](run-workflow.md) 执行；HTML 的数字、发现与原声通过 [报告绑定](report-bindings.md) 检查实际页面，保留实际视觉验收。

先检查目的是否达成：主问题有无回答、比较是否同维度、解释有无证据、矛盾与关键未知是否处理，建议是否对应已知问题。关键数字需要解释其意义，不能靠增加图表、引语或段落补形式。再检查来源、引用资格、统计分母、时间与版本。

按首次阅读顺序检查实际成稿：只看标题、概览和主要图表，能否识别主答案、关键差异与问题；继续阅读，每节是否说清观点，突出引用是否直接支撑相邻判断，建议是否超出证据。通读正文、标签、注释、展开内容和页脚，核对语言、身份与归属。删去重复结论、无任务的模块和制作说明，保留必要证据与条件。

最后实际检查阅读路径和所用交互：总览能否进入主题与原声、筛选范围是否清楚、导航返回与打印是否保留主要分析。按数据与证据、专业语言、信息层级、界面与交互分别保存简短检查记录及修订依据，注明未执行项。脚本只辅助核对结构与回链，不能证明解释成立或报告好读。无法完成渲染时如实说明验收范围。HTML规则见 [report-design.md](report-design.md)。

本轮需要样本分布时，另按 [quantitative-analysis.md](quantitative-analysis.md) 逐项对账研究问题和必需统计表：每项是否生成、能否从明确入口取得，`n/N` 与口径是否可读，未知/排除及多选是否明确，数字是否从冻结分类复算。正文精选能支撑发现的统计，完整表保留可浏览或可下载入口；不能只交有数据来源的案例就标记定量分析完成。
