# 报告的视觉与交互规范

先按 [output.md](output.md) 安排答案和推理，再决定布局。默认采用克制、清晰的专业报告界面。行业、对象数量、章节和导航随研究变化；统一的是阅读层次、可读性和证据规则，不复用某个案例的固定页面结构。

## 语义层级与布局

首屏给主问题、直接回答和关键差异，范围与日期简短可见。会改变当前判断的限定就近用短句说明；通用研究边界、统计细则、编码方法与工具来源集中放“原声与方法”。删除“按问题深入阅读”等导航教学、制作过程汇报和反复出现的使用说明，避免每个模块都附一段免责声明。

用字号、字重、间距和对齐区分结论、支持材料与辅助信息，避免满屏同权重文字。需要横向比较时优先共同维度的表格，需要说明顺序时用有依据的路径；不把每段都装进卡片，不为装饰添加图表或把正文缩成小字。长页先减少重复和拆清阅读任务，再决定目录、分页或独立视图；折叠不能掩盖重要问题或改变结论的条件。

研究正文按发现和读者问题组织，避免将主题、任务、态度、使用状态等全部统计轴依次做成主视图。关键数字可以嵌入判断或小型比较，场景可以用短案例、原声和路径说明；同一组内容不连续重复为条形图、数字表和文字报数。完整分布及明细保留独立入口，主报告的阅读顺序不由校验器的输出顺序决定。选择性展示统计时，影响结论的未知与条件仍就近可见。

指标标签使用读者熟悉且准确的名称，例如“检索笔记”“取得完整文字的笔记”“提取观点”；复杂单位在统计说明中定义。技术ID、纳入理由和校验日志保留在来源详情或方法记录，不默认铺满正文。页脚只保留必要的日期、版本与归属；模型参与方式在方法中如实说明，不虚设研究人员或机构。语言要求见 [report-language.md](report-language.md)。

采用一致的内容网格。可从最大宽度1120–1280px、正文阅读宽度约38–46个汉字、正文16–18px、行高1.6–1.8起步；图表与表格按信息密度调整。标题约28–36/22–28/18–22px三级，辅助文字通常不小于14px。间距可按4/8px步进，组内紧、组间松；这些是可调整起点，不是固定模板。避免同屏多套边框、阴影与强调色竞争。

本项目中文报告默认使用微软雅黑，标题、正文、数字与控件保持同一字体体系。可用字体栈 `"Microsoft YaHei", "微软雅黑", "PingFang SC", "Noto Sans CJK SC", system-ui, sans-serif`，不为字体另装环境或依赖在线字体；后续用户指定字体时以其要求为准。

使用一个主强调色和少量有稳定意义的辅助色。正向/负向、亲历/宣传/未知均有文字标签；不只靠红绿或深浅传意。原声用引用样式和来源说明，与解释区别。按[W3C对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)，普通文本与背景至少4.5:1；符合该标准“大文本”定义的文字至少3:1。不能仅因标题看起来大就降低要求。

## 图表按问题选择

| 阅读任务 | 优先展示 | 必要约束 |
|---|---|---|
| 精确比较产品或主题 | 同维度表、条形图 | 数量/比例标明基数；未知不画成零或叉号 |
| 看构成与极性 | 有数量标签的堆积条 | 仅互斥分类可按100%堆积；多选主题改独立条形 |
| 看时间变化 | 折线或分窗表 | 仅可比连续窗口；缺采显示断点，说明采样变化 |
| 看阶段及障碍 | 汇总旅程矩阵 | 阶段、行为、关注点、情绪、已观测指标与待验证指标分开 |
| 看评价用语 | 正负双云＋排序明细 | 同一公共尺度；标DF与资格；可回到成员原声 |

每图就近给结论型标题、当前对象、单位、必要图例、基数与来源入口；与页面共享的日期和范围不逐图重复。轴标签和原声必须可读；装饰性图标、雷达综合分或圆面积不能替代可靠比较。若数据不足以绘图，用有边界的文字或表格。

词云以横排可读短语为主，不用复杂形状挤字。正负两面共享取值范围和字号函数，页面保留“体验自述 · 按来源去重”等简短口径；平方根/对数变换、提取过程和未提词理由放方法页或可展开详情。字长不同不宣称面积严格正比。精确比较依靠排序数字，完整词表可查；筛选重算尺度时用短状态提示，默认跨视图保持可比。提词见 [keyword-method.md](keyword-method.md)。

## 分类、筛选与访问

按阅读任务选择导航。连续阅读可以使用章节和目录；采用 Tab 时，每项对应独立分析问题，名称与数量按实际内容决定。只有读者需要缩小材料范围时才增加筛选；产品、极性、来源性质、阶段可作为独立维度。各视图共用观点、主题、发现和证据ID。使用筛选时显示当前范围及去重数量，结论同步限定，或明确“以下综合结论仍基于全量研究”；零结果有清除入口。

观点分类页按“主题导航 → 主题摘要 → 筛选与数量 → 原声列表”组织。桌面可用稳定侧栏，窄屏改横向主题导航；主题标题与来源规模保持整齐，选中态清楚。摘要先讲差异，详细定义与一般边界可展开；筛选紧贴受其影响的原声列表，完整样本的摘要另标“全样本”。原声卡片按产品、方向/性质、观点、引语排序；同一条不重复显示角色徽标、来源编号和上下文链接。场景、行为与技术ID放补充详情，影响评价成立的条件仍就近可见。

比较单元格、关键词和旅程阶段能进入相应原声，关键词用已记录归并成员匹配，不用模糊命中冒充支持。证据入口有明确可访问名称，不能只向辅助技术提供无含义的编号。支持深链接、返回及上下文恢复；证据性质、未知值和改变具体结论的条件不藏在详情中。

窄屏将宽表转为带字段名的卡片，或只让表格自身横向滚动，保留行列含义；避免整页溢出。长链接可断行，标签/轴/原声不靠缩成小字解决。Tab有角色、选中状态、关联面板和可见焦点；键盘箭头/Home/End与所用模式一致。筛选有名称，动态结果对辅助技术可达。默认本地字体和资源，不依赖外部CDN或动画。

## 降级、打印与验收

无JavaScript时主答案和主要分析仍可读，证据文件可访问。打印将主要分析Tab连续展开，保留必要原声与来源；完整原文库单独导出，不打印成几百页。明确导出使用全量还是当前筛选，避免屏幕与纸面口径冲突。

先验收扫描可读性与密度：主要结论是否突出、相邻层级是否可区分、表格能否横向比较、是否还有连续大段文字或反复概括；不能只确认元素存在。再在桌面与窄屏实际检查布局、键盘、所用筛选及清空、深链接/返回、打印分页，以及从结论到原声的完整路径。记录环境、已执行项目、发现的问题与未完成项；源码/纯函数校验不等于浏览器交互、视觉或无障碍验收，未渲染的交付物不能声称视觉验收通过。
